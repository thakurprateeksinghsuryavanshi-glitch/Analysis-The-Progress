## 🌐 Deploy on GitHub Pages

1. Upload `index.html` (and optionally `sample_data.json`) to a GitHub repo
2. Go to **Settings → Pages → Source → Deploy from branch → main / root**
3. Your dashboard is live at `https://yourusername.github.io/repo-name`
